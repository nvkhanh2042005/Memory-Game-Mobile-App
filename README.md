# 🧠 Memory Card Game - Ứng Dụng Trò Chơi Rèn Luyện Trí Nhớ (Android)

Dự án phát triển ứng dụng di động trò chơi giải đố lật thẻ tìm cặp giống nhau (**Memory Card Game**) được xây dựng bằng ngôn ngữ **Java** trên nền tảng Android. Ứng dụng mang lại trải nghiệm giải trí nhẹ nhàng, giúp người chơi rèn luyện khả năng tập trung và trí nhớ ngắn hạn thông qua giao diện trực quan, hiệu ứng mượt mà.

---

## ✨ Tính Năng Nổi Bật

* **Lối chơi lật thẻ cổ điển:** Tìm và ghép các cặp thẻ hình ảnh giống nhau trong thời gian hoặc số lượt lật tối ưu nhất.
* **Nhiều cấp độ thử thách:** Đa dạng kích thước lưới thẻ (Dễ, Trung bình, Khó) phù hợp với mọi đối tượng người chơi.
* **Hệ thống tính điểm & Thời gian:** Theo dõi thời gian hoàn thành màn chơi, đếm số lượt lật và lưu kỷ lục điểm số cao nhất.
* **Hiệu ứng trực quan & Âm thanh:** Hiệu ứng lật thẻ 3D mượt mà kết hợp âm thanh tương tác sinh động khi chọn đúng/sai cặp thẻ.
* **Giao diện thân thiện:** Thiết kế tối ưu cho màn hình thiết bị di động Android, dễ thao tác.

---

## 🛠️ Công Nghệ Sử Dụng

* **Ngôn ngữ lập trình:** Java (100%)
* **Môi trường phát triển (IDE):** Android Studio
* **Giao diện (UI):** XML Layout
* **Lưu trữ cục bộ:** SharedPreferences / SQLite (lưu điểm cao và cài đặt)
